# 刘洋 LIUYANG · 剪辑师作品集网站

## 目录结构（部署时请保持相对路径不变）

```
站点根目录/
├── index.html
└── assets/
    ├── resume-liuyang.pdf      ← 简历下载文件（「下载简历 PDF」按钮指向它）
    ├── posters/           ← 视频海报帧（首帧即时显示）
    └── videos/            ← 已改为英文文件名，避免编码问题            ← 已放入 3 个项目视频（H.264，全浏览器可播）
        ├── 益生菌30s开屏.mp4   ← 首屏背景 & 作品1
        ├── 驼奶粉30s开屏.mp4   ← 作品2
        └── 驼奶粉15s电梯.mp4   ← 作品3
```

## 说明
1. 3 个视频已就位：H.264 编码 + 竖屏 9:16 完整显示（不裁切），全部为站内相对路径，无外部链接。
2. 每个视频配有海报帧，加载前即显示首帧画面。
3. 首屏背景视频静音、循环、内联播放；任意时刻全站只有一个视频在播放（作品视频播放时背景自动暂停，结束后自动恢复）。
4. 未提供的板块（所在城市、B站/视频号）已按要求隐藏，无占位内容。
5. 无人物图、无赛博朋克/科技感元素、无花哨动效；整体深色极简、电影感。
6. 「简历」板块附「下载简历 PDF」按钮；联系区微信卡片点击可复制微信号。

## 替换 Showreel
首屏当前默认使用「益生菌30s开屏.mp4」作背景。
如有单独 Showreel，可放入 `assets/videos/showreel.mp4`，然后把 index.html 中
`id="bgVideo"` 的 video 标签 src 改为 `assets/videos/showreel.mp4`。
